# Meow Dumplings (Meow Dumpling House)

Native TikTok Minis package for Meow Dumplings, the dumpling/dim sum reskin of Meow Dessert Shop.

- `game.js` — game code (generated by `build_native.py`, readable, not minified)
- `hs-game.js`, `hs-sdk.min.js` — HS SDK kit
- `images/`, `audio/` — assets
- `game.json`, `project.config.json` — TikTok Minis config

Before packing: copy `hs-key.example.js` to `hs-key.js` and paste the HS SDK key. `hs-key.js` is git-ignored, but it must be inside the TikTok zip.

Zip the contents of this folder (not the folder itself) to upload to TikTok.
